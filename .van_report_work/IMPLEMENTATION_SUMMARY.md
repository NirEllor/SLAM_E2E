## Key Design Decisions

1. **Anti-Fabrication Spine:** No claim involving a number, file path, or function name is written directly into reports. All must first exist as VERIFIED entries in `evidence_ledger.json`.

2. **Live Discovery Over Hardcoding:** The discovery script actively globs `outputs/` directories and loads the real `tracking_db.pkl` rather than assuming hardcoded filenames. This makes it resilient to naming changes.

3. **Pattern-Based Graph Matching:** Graph filenames weren't standardized, so matching uses substring keywords (e.g., "kitti", "pnp", "angle") rather than exact names, allowing discovery of variants.

4. **External Savefig Wrapper (Non-Invasive):** Rather than edit source code, missing graphs are regenerated by calling the existing functions and immediately saving the figure. This is reversible and safe.

5. **Verified Evidence Ledger:** Every entry is JSON-serialized with status, claim, and evidence details, enabling future audits and updates.
